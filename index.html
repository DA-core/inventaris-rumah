01 — URL Google Apps Script

Paste URL Apps Script Anda di sini. Setelah itu setiap scan otomatis tercatat ke Google Sheets.

02 — Struktur Google Sheets

Jalankan fungsi initSheets() di Apps Script untuk membuat sheet otomatis. Pastikan kode Apps Script sudah dipaste dari file yang sudah diberikan sebelumnya.

03 — Deploy Web App

Deploy → New Deployment → Web App → "Anyone" → copy URL → paste di kolom atas.

💡 Scan akan tetap berfungsi offline (stok tersimpan di HP). Data dikirim ke Sheets hanya jika URL sudah diisi dan HP terhubung internet.
